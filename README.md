# 穿搭助手（green-hand-attire）

一个纯本地的穿搭建议小应用：录入今天/明天的天气，按「体感温度」给出穿搭方案，支持性别与身体体质（抗冻/不抗冻、耐热/怕热）选择，记录每日穿搭反馈后逐步个性化，并提醒长期未穿的衣物类别。

## 使用

1. 直接双击打开 `index.html`（单文件，数据存浏览器 localStorage，无需服务器）。
2. 到「衣橱」页点「一键加入常用单品」，到「我的」页选性别与体质。
3. 回「今日」页，填写城市点「拉取今明天气」自动获取（也可手动录入），查看建议，睡前点「记录今天的穿搭」反馈冷暖。

## 特性

- 天气自动拉取（Open-Meteo，免费无需 key）+ 手动录入降级
- 体感温度换算（体质偏移 + 风力修正）
- 规则表打底 + 反馈微调（冷暖反馈逐步校准个人体感）
- 简化衣橱（类别 + 厚薄 + 穿搭风格）+ 类别级长期未穿提醒
- 基础统计（穿着频率、冷暖反馈分布）
- JSON 数据导入 / 导出备份

> 说明：天气自动拉取会把城市名发送给 Open-Meteo 用于查询（仅此一项联网，其余数据均只存本机）。
